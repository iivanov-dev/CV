Одностраничный сайт-резюме, разработанный на чистом HTML, CSS и JavaScript в рамках вступительного задания.

Сайт опубликован и доступен по ссылке:  
https://iivanov-dev.github.io/CV/

Все требования соблюдены:
- Одностраничный сайт-резюме с реальной информацией о себе.
- Интерактивный раздел «Навыки» с фильтрацией по категориям и текстовым поиском (фильтры работают совместно).
- Переключение между светлой и тёмной темой с сохранением выбора в localStorage.
- Интерфейс корректно отображается на десктопах и полностью адаптирован под брейкпоинты 768px и 375px
